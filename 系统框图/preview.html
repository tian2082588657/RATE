3. 关键路径与设计点 / Key paths and design points

  1. 编码决定检测，归约只是压缩。 主数据流沿“原始审计记录 → 规范化溯源图 → 归约图 G' → RATE* 描述子 → 无标签单类集成 → 预算化告警聚合”传递；去掉拓扑通道后，归约图与未归约图同样不可检测（node F1 ≈ 0.007 vs 0.005）。
  2. 归约与编码解耦：R 负责压缩，RATE* 负责可读。 归约算子 R 输出节点映射 π 与边质量 μ；RATE* 用 4 通道（in/out count + in/out collapse ratio）与 TAPE 正弦投影重建被移动或删除的度信息，且 μ≡1 时退化为普通度编码。
  3. 训练控制与真值监督严格分离。 训练窗口仅用于提取模板和无标签单类集成；真值标注仅在评估阶段使用，避免标签泄露。
  4. 原单位映射让归约与未归约公平可比。 告警簇通过 π 回映到原始实体，得到共单位召回，是 identity、TeRed+count、TeRed+RATE* 及等宽对照比较的唯一公平单位。
  5. 外部依赖全部以“对照”方式接入。 StreamSpot 作为第二语料复现输入/预处理链路；Kairos / FLASH / THREATRACE 与消息传递检测器均以同图、同正例方式接入评估指标，不混入主数据流。
